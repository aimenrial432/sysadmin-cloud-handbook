# 📚 SysAdmin & Cloud Handbook

Centralized technical knowledge base built in **Obsidian** and synced via Git across desktop and mobile devices (**PC, iPad, iPhone**). Designed as a structured single source of truth for certification study paths, architectural references, CLI cheat sheets, and production operational notes.

---

## 🎯 Purpose & Philosophy

- **Structured Learning:** Distills complex certification curricula and technical documentation into concise, exam-ready and production-ready Markdown notes.
- **Hands-On Alignment:** Paired directly with practical labs and automation scripts in **[sysadmin-infra-labs](https://github.com/aimenrial432/sysadmin-infra-labs)**.
- **Multi-Device Accessibility:** Clean Markdown formatting optimized for seamless reading and quick command lookup across desktop workstations and mobile devices.

## 📐 Note-Taking Standards

Every module inside this handbook follows a consistent technical structure:
1. **Core Architecture & Mental Model:** High-level concepts, service boundaries (Global vs. Regional), and design trade-offs.
2. **Configuration & Policy Templates:** Annotated JSON/YAML snippets, security rules, and architectural diagrams.
3. **CLI Quick Reference:** Ready-to-run terminal commands for provisioning, auditing, and troubleshooting.
4. **Exam & Production Gotchas:** Key edge cases, security pitfalls, and operational best practices.
